# Rough CAD / model set for S-LX (UKROC 2027 competition)

Each rocket gets a small, reviewable model bundle. For this rocket:

| File | What it is |
|---|---|
| `models/S-LX.ork` | OpenRocket design used for the F32 reference flight |
| `models/S-LX-ESP32C3.ork` | Variant carrying the unchanged Rust guidance stack |
| `models/S-LX-STM32F103.ork` | Variant carrying the FC6-II STM32 profile |
| `fin_plate.stl` | One movable fin plate, generated by `generate_fin_plate_stl.py` |
| `../model.yaml` | Dimensions, motor, target, aero inputs and links to these files |

The ogive nose cone STL is generated by `cad/generate_nose_cone_stl.py` in the
main rocket project (66 mm OD, 150 mm long). The full rocket envelope used by
FluidX3D is `rocket/cfd/fluidx3d/UKROC_2027_cfd.stl` there. Neither is copied
into this PR: they are large generated artefacts and the OpenRocket designs
plus `model.yaml` are the authoritative, diffable description.

`fin_plate.stl` is intentionally small (12 triangles). It carries the planform
from the frozen CFD manifest — 74 mm root chord, 50 mm tip chord, 100 mm span,
25 mm leading-edge sweep, 3 mm thickness — with the hinge at `x = 0`. Rotating
it per state gives the STL-per-state inputs described in `../cfd/README.md`.

These are engineering models, not manufacturing drawings. Dimensions must be
checked against the flown airframe before any structural or recovery claim.
